# 过程播报设计规范

## Overview

用户通过输入框右侧的气泡查看和调整播报频率。面板保留一行当前频率说明、重置和三个等宽档位。默认选中「标准」。

## Colors

面板、文字、焦点和轨道跟随 Harness 主题。选中胶囊以宿主业务色为底，向宿主主文字色调和，搭配宿主反色前景。在浅色和深色主题中分别检查文字对比度，档位文字至少为 4.5:1。

## Typography

继承宿主字体。档位使用等宽分栏，选中文字用更高字重；频率说明使用次要文字色，与左侧气泡对齐。

## Layout

面板锚定在气泡上方并由宿主管理视口边距。轨道的内容区决定三个档位的视觉宽度和点击边界。

## Elevation & Depth

浮层复用宿主 `MenuSurface` 和 prominent 阴影。选中胶囊的轻阴影用于区分它和轨道。

## Shapes

面板沿用宿主大圆角。轨道与选中项使用完整胶囊，两端明确采用圆形曲线。

## Components

| 组件 | 状态与行为 |
|---|---|
| 气泡入口 | 以图形和无障碍名称反馈已保存档位。打开后焦点进入分段控件。 |
| 分段控件 | 克制、标准、话多。点击选档，拖动只预览，释放后吸附并保存变化。方向键逐档调整，Home 和 End 跳到两端。 |
| 重置 | 将档位恢复为标准。已是标准或设置未就绪时禁用。 |

## Do's and Don'ts

保留可见的档位名称和当前节奏说明。用颜色和字重标明选中态，胶囊内保持无装饰。尊重系统的减少动态效果设置。拖动中的 Escape 取消预览，面板中的 Escape 关闭面板并把焦点还给气泡。

## Implementation Mapping

[client.js](client.js) 维护组件样式与交互。主题色值来自 Harness，插件在组件内定义颜色用途和组合。README 图片作为示意素材，运行界面以实际加载的组件为准。

改动后在 Harness 中检查两个主题的档位可读性、打开与关闭焦点、点击与拖动保存、重置及禁用状态。指针交错和取消可从源码仓库运行 `node --test` 检查。
